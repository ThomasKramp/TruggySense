## FreeCAD

The following files and folders are present and contain the following:

- **base_plate.FCStd**: Contains the base plate that acts as the mounting point for all modules developed. This plate is cut out of a plexi-plate with a thickness of 5mm.
- **Wheel_encoder.FCStd**: Holds the front and back bracket to mount the HAL sensor. Additionally, the encoder ring is configured to have 14 magnets. You can change this in the *PolarPattern* to whatever number is possible on the ring encoder.
- **RC_1-8_Kagama_custom_mount.FCStd**: Contains the base plate holders onto the Kagama frame, the Nvidia Jetson mount, the X6B receiver holder, and some cable management brackets.
- **RC_1-10_Truggy_Platform.FCStd**: Has a custom motor mount for another vehicle of scale 1/10. It was created, but the preferences went to the 1/8 scale vehicle.
- **DXF**: Contains exported DXF files such as the base plate.
- **STL**: Contains STL files of all FreeCAD created objects. Nevertheless, you can change them in FreeCAD and re-export them as STL.
