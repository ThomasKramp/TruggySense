## OpenSCAD

The following files and folders are present and contain the following:

- **base_holder.scad**: the holder to hold the circuit_plate_holders.
- **Circuit_plate_holder.scad**: slide-in holder for my custom made PCBs.
- **Circuit_plate_holder_base_station.scad**: slide-in holder for the perfboard.
- **Circuit_plate_holder_current_senses.scad**: plate to mount the current sensors and NRF24 module V1.
- **circuit_plate_holder_current_senses_V2.scad**: plate to mount the current sensors and NRF24 module V2.
- **circuit_plate_holder_gps.scad**: slide-in case for the GPS module.
- **circuit_plate_holder_imu.scad**: slide-in case for the IMU module.
- **stencil.scad**: script to extract a stencil based on a DXF Paste layer.

In the next generation, a custom-made PCB must be created to ease the usage of this framework.  
Thus, these `circuit_plate_holder` have no use in the future.
