\doxysubsection{Detailed Description}
In this file, all tasks their function names will be defined and a brief description of what the tasks include. 

\begin{DoxyAuthor}{Author}
Robbe Elsermans
\end{DoxyAuthor}
Here, all task files will be defined and their datastructure. A task will run off a certain moment in time which are defined by TIMER\+\_\+\+INTERVAL\+\_\+\{task name\}. These timers are set to a value which is partly derived from the proposal document. Nevertheless, some timer intervals have been lowerd due to the fact that the drivers required this.\+ADC\+\_\+\+ETC\+\_\+\+CTRL\+\_\+\+DMA\+\_\+\+MODE\+\_\+\+SEL

If you want to lower a certain task, thus increase the sample rate, you need to check if a tasks total duration is not longer than the task interval rate. This is easly done by using millis() and Serial.\+print() at the beginning and ending of a task to have insights in the duration of the task.

Remember to also increase the logging rate TIMER\+\_\+\+INTERVAL\+\_\+\+LOG and save rate TIMER\+\_\+\+INTERVAL\+\_\+\+SAVE\+\_\+\+LOG to actually save the sampled data.

When one would expand the datastructures with more data, they must be aware of the concequences.


\begin{DoxyEnumerate}
\item Changing the tasks such that the datastruct is filled in 
\item Changing the datastruct for logging in \mbox{\hyperlink{sd__logger_8h}{sd\+\_\+logger.\+h}}. Make sure to follow the sorting here (internally, data is stored aligned) 
\item Changing the \mbox{\hyperlink{tasks_8h_af30f2fc173d77001cb45558437c552fb}{task\+Log()}} and \mbox{\hyperlink{tasks_8h_a5591a493a42241bbcc3102c4052bb2fa}{task\+Save\+Log()}} tasks 
\item Changing the \mbox{\hyperlink{base__station_8h}{base\+\_\+station.\+h}} such that the correct chuncks and payload size is entered 
\item Changing the node-\/red backend such that the binary file is decoded correctly 
\item Changing the base\+\_\+station receiver nrf\+\_\+rx to match the datastructure in \mbox{\hyperlink{sd__logger_8h}{sd\+\_\+logger.\+h}} 
\end{DoxyEnumerate}

I know, adding a byte is cumbersome. If you want, you can change the code such that it becomes easier to add or remove code. -\/\texorpdfstring{$>$}{>} base\+\_\+station could be initialized with the total payload which then can be sliced to 30 byte chunks inside the driver for instance.
