\doxysubsection{Detailed Description}
A driver to drive PWM controlled modules such as the ESC and Servo. 

\begin{DoxyAuthor}{Author}
Robbe Elsermans
\end{DoxyAuthor}
The PWM modules will be actuated through the duration in microseconds which goes from 1000µs to 2000µs. In order to use PWM in conmination with interrupts, PWMServo.\+h is used instead of Servo.\+h. See $<$href src=\char`\"{}https\+://www.\+pjrc.\+com/teensy/td\+\_\+libs\+\_\+\+Servo.\+html\char`\"{}$>$here$<$/href$>$ why.

\begin{DoxyNote}{Note}
I\textquotesingle{}ve added a detach() function to the PWMServo.\+cpp which does the job for me because it was not implemented by default.
\end{DoxyNote}
