Detailed Description

Initialize, read and get the Euler or Quaternion specific angles given by e_imu_data from the BNO085 IMU 9-axis sensor.

Note
This driver assumes the IMU is connected in the following way
MCU IMU
VCC (3V3) -> VCC (3V3),
SDA (18) -> SDA,
SCL (19) -> SCL,
GND -> GND
