Detailed Description

The base station class file which is used for sending telemetry data.

Author
Robbe Elsermans

Will cut the data into chunks of chunk_size. Is created to work for nrf24 boards that have a maximul payload size of 32 byte per transfer. It uses the logging_data_t data structure originating from sd_lohher.h.
