Detailed Description

A driver to drive PWM controlled modules such as the ESC and Servo.

Author
Robbe Elsermans

The PWM modules will be actuated through the duration in microseconds which goes from 1000µs to 2000µs. In order to use PWM in conmination with interrupts, PWMServo.h is used instead of Servo.h. See <href src="https://www.pjrc.com/teensy/td_libs_Servo.html">here</href> why.

Note
I've added a detach() function to the PWMServo.cpp which does the job for me because it was not implemented by default.
