Detailed Description

Encoder class that will manage the interrupts triggered by the encoders and calculate the RPM within the trigger interval of getWheelSpeed().

◆ getWheelSpeed()

float Encoder::getWheelSpeed ( position  pos)

Get the Wheel Speed in RPM.

Will calculate the RPM of a given wheel position defined by position. It will use the pulse counter from the wheel pin in combination with the duration between triggers of this method.

Parameters
poswhich position
Returns
float the RPM

Example

Given: N_MAG=40, DELTA=0.1, COUNTER=2,

if we have 2 counts in the period of 0.1s, this means that for 1 second, we must divide this counter with 1/0.1=10 which yields 20 counts -> 20/40 = 0.5 Hz so we have a rotation speed of 0.5 Hz. -> F_WHEEL=(1/DELTA)*(COUNT/N_MAG)
