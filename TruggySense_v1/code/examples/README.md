## Examples
The eamples or playroom consists of all modules and sensors' sketches. Often, these sketches are used to learn the sensor and to create for instance a driver for the main program.

- [ArduinoIDE](ArduinoIDE/): Contains the ArduinoIDE `.ino` files which were developed in the Arduino IDE 1.8.19.
- [CLion](CLion/): Contains the mock data creator and the packet chunker idea used in the real-time monitoring using the NRF24 RF modules.
- [PlatformIO](PlatformIO/): Contains all sketches for all modules and sensors developed in the Visual Code extension [PlatformIO](https://platformio.org/).

> **Note**: The drivers used here are often outdated compared to the LowLevelController software.
